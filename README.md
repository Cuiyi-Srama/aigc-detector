# AIGC 文本检测器

基于文本统计特征与大模型困惑度的 AI 生成内容（AIGC）检测工具。支持 **Android APK 本地检测**与 **PWA 在线检测**双引擎，中英双语，全流程开源。

---

## 功能概述

- **快速检测（统计特征）**：基于句长分布、词汇多样性、模板套话、标点使用等文本统计特征计算 AI 生成概率，秒级返回
- **深度检测（双引擎）**：
  - **本地引擎**：加载本地 GGUF 模型（Qwen3-4B / Gemma-2B），基于困惑度、可预测率、分段波动等指标，纯离线
  - **在线引擎（v8.3）**：DeepSeek API 逐位置采样（约 120 个位置），困惑度估计更可靠，已配置 Key 时自动优先
- **分类型指纹**：按文章类型（学术 / 新闻 / 文学 / 网络 / 公文）分别校准统计基准，降低跨类型误判
- **在线校准（v8.3）**：内置 219 篇标注语料，渐进式断点续跑校准（AI / 人类双分布 + 按类型分组指纹），消耗约 0.2-0.5 元 DeepSeek 额度
- **PWA（v8.3）**：网页版可安装到主屏幕（Android / iOS），Service Worker 离线缓存
- **中英双语**：自动识别语言，分别加载对应模型
- **检测历史**：本地保存最近 10 次记录，支持导出

## 架构

```
┌─ 前端（单文件 index.html，APK assets 与网页版共用同一份）
│   ├─ 快速检测：文本统计特征（句长/词汇多样性/模板/标点）
│   ├─ 本地深度检测：AndroidBridge → llama.cpp（JNI）加载 GGUF
│   └─ 在线深度检测：fetch → api.deepseek.com（logprobs 采样）
│       ├─ 采样引擎：120 位置均匀采样 × top_logprobs=20 候选匹配，并发 10
│       ├─ 校准：219 篇语料 → 高斯朴素贝叶斯（AI/HU 双分布 + 类型分组）
│       └─ 融合：快速分×0.55 + 深度分×0.45（z-score 截断 + 饱和回退）
├─ Android 壳：WebView + Kotlin + C++ JNI（LlmProEngine）
└─ CI：GitHub Actions 构建 APK → 上传 artifact → 网页版 Pages 自动部署
```

## 深度检测原理

让大语言模型逐词预测目标文本：AI 生成的文本可预测性高（困惑度低、top-1 命中率高），人类写作难以预测（困惑度高、波动大、罕见词多）。

| 指标 | 含义 | AI 倾向 |
|------|------|---------|
| 困惑度 (ppl) | 模型预测的平均困难度 | 低 |
| top-1 可预测率 | 模型首选词命中真实词的比例 | 高 |
| top-5 可预测率 | 前 5 候选命中比例 | 高 |
| 分段波动 | 各分段困惑度的变异系数 | 低（风格均匀） |
| 罕见词率 | 预测排名靠后的位置占比 | 低 |

## 类型指纹（v8.2）

不同类型的文章，AI 生成风格差异较大——学术论文本身高度结构化，文学创作则相对自由。使用统一阈值容易跨类型误判，故按类型分别校准：

| 类型 | 说明 |
|------|------|
| 通用 | 不指定类型，使用全局混合基准 |
| 学术论文 / 研究报告 | 摘要-引言-方法-结论结构，专业术语密度高 |
| 新闻报道 / 时评 | 客观叙事与时效性表达 |
| 文学作品 / 散文 | 风格自由，人类写作波动较大 |
| 网络文章 / 科普 | 自媒体 / 博客 / 问答风格 |
| 公文 / 演讲稿 | 正式文书，固定搭配较多 |

**指纹来源**（版权安全语料）：HC3 开源数据集、公版散文与杂文（维基文库）、Project Gutenberg 公版英文文学、arXiv 开放论文、美国建国文献（人类）；主流大模型生成文本（AI）。本地引擎用 Qwen3-4B 对 218 篇语料实测拟合（回测准确率 94.0%）；在线引擎在用户首次校准时按类型分组实时拟合。

## 在线检测使用

1. 打开网页版或 APK → 「在线检测」面板
2. 注册 [DeepSeek 开放平台](https://platform.deepseek.com/)，创建 API Key（费用由用户自行承担，本项目开发者不收取任何费用）
3. 填入 Key 并选择模型（默认 `deepseek-v4-flash`，低成本）
4. 点击「开始校准」（约 10 分钟，可中断续跑，消耗约 0.2-0.5 元）
5. 输入文本 → 选择文章类型 → 深度检测（约 30-90 秒）

> Key 仅保存在浏览器 localStorage，不会上传至任何第三方服务器。

## 本地深度检测（APK）

1. 下载 [GGUF 模型](https://huggingface.co/)（Qwen3-4B 中文 / Gemma-2B 英文）
2. App 内点击「选中文 / 选英文」扫描模型文件
3. 输入文本 → 深度检测（本地推理约 1-3 分钟）

## 数据与隐私

- 本地模式：所有处理在设备端完成，文本不上传
- 在线模式：文本切片发送至 DeepSeek API 用于逐位置预测，仅用于检测，不存储
- 检测历史保存在本地
